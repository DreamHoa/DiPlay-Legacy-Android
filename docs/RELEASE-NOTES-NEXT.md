# DiPlay Okavango 0.3.1

面向 2023 菲律宾 Geely Okavango / Android 5.1（API 22）。

- 修正首次连接状态误重置：CarPlay 已完成 RECORD 后，重复的 iAP2 可用通知不会再清除已连接标志。
- 修正 RECORD 先于启动日志回调到达时，已连接标志被后到的日志回调覆盖的竞态。
- 仅在开始新的 USB/NCM 数据通路时清除旧标志；没有真正建立会话时仍保留原来的 30 秒启动失败保护。
- 连接状态不依赖音乐播放或画面持续更新。启动回复日志包含 establishedAirPlay，便于核对后续实车断连。
- 新增 Android API23 / API28 回归用例：无 RECORD、RECORD 抢先、无音视频的重复启动通知、含启动字样的超时诊断。Robolectric 4.17 最低支持 API23，API22 兼容性仍需在车机验证。
- 包名和签名身份不变，版本码升至 73；可覆盖同签名的 0.3.0。

这是已确认代码路径的修复，尚未通过实车证明它就是用户空闲重连的唯一原因。
此前移除 90 秒 iAP2 静默重置，并未解决用户在 413812c 上观察到的全部空闲重连。
需在实车空闲至少 3 分钟，并复查有线连接、音乐、触摸、方向盘与重新插拔。
若仍断开，立即保存诊断报告，区分首次连接误判、手机 EOF、事件通道或 USB 错误。

正式 APK 使用固定签名并包含认证材料；Release 保留为草稿。
